# Аудит безопасности NetFreedom 3.3.0 — 10 ноября 2026

**Объём.** Статический разбор исходников: движок (`engine.rs`, `tcp.rs`, `tls.rs`, `quic_sni.rs`, `native.rs`),
запуск внешних программ, загрузка списков, автозапуск, удаление, скрипты DNS, CI (`release.yml`), зависимости,
вложенные бинарники. **Не сделано:** запуск на Windows, полное чтение `dns.rs`/`tune.rs`/`profiles_data.rs`,
реверс `WinDivert.dll`, `WinDivert64.sys` и `nfqws`. Проверок «чисто» это не гарантирует.

## Что сделано хорошо
Абсолютные пути системных программ (`system_tool`), `curl` только по HTTPS с TLS 1.2+, PowerShell с проверкой входов
(есть тест на подмену DoH-адреса), защита от удаления системных папок в деинсталляторе, мьютекс на один экземпляр
движка, `WinDivert.dll` грузится по полному пути, нет входящих сетевых слушателей (только исходящие сокеты),
зависимости только `libc` и `windows-sys`, у релиза есть SHA256SUMS и attestation.

## Риски самих изменений
Захват всех исходящих данных на портах правил со списками хостов (как у winws) повышает нагрузку на CPU при больших
выгрузках; движок однопоточный.
