# NetFreedom

Открытый, локальный и обратимый инструмент доступа к открытому Интернету из России.
Два режима работы в одном исполняемом файле:

| Режим | Команда | Что делает |
|---|---|---|
| **Игры через WARP** (по умолчанию) | `netfreedom start` | zapret защищает только рукопожатие Cloudflare WARP (QUIC/UDP), весь игровой трафик идёт внутри туннеля |
| **Обход без WARP** | `netfreedom start --bypass` | стратегия сама разблокирует сайты за Cloudflare, YouTube, Discord (и, по желанию, порты игр) |

Windows: `winws` + WinDivert. Linux: `nfqws` + nftables. Философия проекта: [PHILOSOPHY.md](PHILOSOPHY.md)
(или `netfreedom about`). Репозиторий: https://github.com/PsyGioX/NetFreedom

## Быстрый старт

```text
netfreedom                       интерактивное меню
netfreedom tune                  подобрать лучшую стратегию для игр на вашем провайдере
netfreedom tune --bypass         то же для обхода без WARP (по реальным загрузкам)
netfreedom start                 запуск; Enter в окне = остановить и всё вернуть
netfreedom doctor                диагностика системы
netfreedom verify                проверка целостности пакета (SHA-256)
```

Нужны права администратора (Windows) или root (Linux). Окно не закрывается само: результаты
всегда остаются на экране до нажатия Enter.

## Что изучено и как это отражено в стратегиях

* **ТСПУ** классифицирует соединение по первым пакетам (SNI в TLS ClientHello, QUIC Initial).
  Если классифицировать не получилось, для адресов Cloudflare включается «запасной» режим:
  пропускается лишь около 16 КБ ответа (с 9 июня 2025 у Ростелекома, МТС, МегаФона, МГТС и др.).
  Поэтому проверка обхода — это скачивание файла **больше 16 КБ с Cloudflare**, а не пинг.
* **Фейки с «прошлым» номером последовательности** (`badseq` по умолчанию) ТСПУ начал наказывать
  разрывом соединения (youtubeUnblock#356). В новых стратегиях таких нет: только `ts`, низкий TTL,
  «будущий» seq или вообще без фейков.
* **Перехват DNS** к 8.8.8.8 / 1.1.1.1 через ТСПУ (wiki.zapret.moe, август 2026): `doctor` и
  `tune --bypass` честно показывают, что именно не открылось, а не скрывают проблему.
* **WARP/MASQUE** идёт по QUIC на UDP 443 (+ 500, 1701, 4443, 4500, 8095, 8443) к диапазонам
  Cloudflare. Стратегии WARP выбирают пакеты по IP-диапазону на уровне WinDivert и **не зависят
  от файлов списков**. В старом наборе при `ipset = none` защита рукопожатия молча отключалась.

> Эти выводы получены из публичных источников и кода. На живом ТСПУ каждого провайдера всё
> ведёт себя по-своему — поэтому в проекте есть `tune`.

## Оптимизация для игр

* WARP-стратегии трогают только рукопожатие (UDP к Cloudflare), нулевые накладные расходы на игровой трафик.
* Игровые порты (режимы 2 и 3 обхода) получают только фейки, только в первых двух пакетах потока;
  реальные данные игры не расщепляются и не перекрываются.
* `tune` по умолчанию ранжирует по «игровой» формуле: джиттер ×3, хвост (p95 − медиана) ×0,5,
  потери ×50. Стабильные 40 мс лучше «25 мс со скачками до 90». `--plain-score` — старая формула.
* Цель измерения задаётся `--target <IP игрового сервера>`.
* Процесс движка работает с повышенным приоритетом, на Linux правила очереди работают в режиме
  fail-open (при падении nfqws трафик не блокируется).

## Сборка и проверка

```text
cargo test                                   # 61 тест
cargo build --release                        # Linux
cargo build --release --target x86_64-pc-windows-gnu   # Windows (иконка встраивается через windres/rc)
cargo build --example dump_args && python3 tools/validate_strategies.py   # все стратегии в настоящем nfqws --dry-run
python3 tools/gen_strategies.py > src/profiles_data.rs   # пересборка таблицы стратегий
```

Иконка: `assets/netfreedom.ico` (встроена в exe), `assets/netfreedom.png`.

## Доверие Windows

SmartScreen и антивирусы осторожно относятся к новым неподписанным программам, особенно с драйвером
перехвата пакетов. Что с этим делать автору и пользователю: [docs/WINDOWS-TRUST.md](docs/WINDOWS-TRUST.md).
Кратко для пользователя: скачивайте только с Releases, сверяйте `Get-FileHash`, запускайте `netfreedom verify`.
