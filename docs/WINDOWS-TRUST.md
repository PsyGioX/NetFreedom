# Как получить доверие Windows к NetFreedom

Коротко: **мгновенного способа нет**. Доверие складывается из трёх вещей: проверяемости (любой может
убедиться, что файл собран из вашего кода), цифровой подписи и накопленной репутации. Ниже по порядку:
что происходит, что делать вам как автору, что делать пользователю.

## 1. Почему Windows предупреждает

| Механизм | Что проверяет | Что с этим делать |
|---|---|---|
| **SmartScreen** | репутацию файла (по хешу) и издателя. Без подписи **каждая новая версия начинает с нуля**; с подписью одного издателя репутация переносится между версиями | подпись + стабильный источник загрузки + время |
| **Smart App Control** (Windows 11) | может блокировать неподписанные файлы без положительной репутации | подпись |
| **Антивирусы** | эвристики; программы с драйвером перехвата пакетов (WinDivert) и «обходом блокировок» часто получают метки вида HackTool / RiskWare | заявки о ложном срабатывании, прозрачная сборка |

Важное из документации Microsoft (Microsoft Learn, «SmartScreen reputation»):

* сертификаты **EV больше не дают мгновенной репутации** (так было до 2024);
* **вручную отправить файл на проверку репутации SmartScreen для обычных пользователей нельзя**,
  репутация накапливается через загрузки;
* даже подписанный новый файл может какое-то время показывать предупреждение: подпись делает
  предупреждение про «малую репутацию», а не про «неизвестного издателя».

## 2. Что сделать вам (автору), по убыванию отдачи

### 2.1. Прозрачная и проверяемая сборка (бесплатно, делается сразу)

1. Публичный репозиторий https://github.com/PsyGioX/NetFreedom, лицензия GPL-3.0, исходники с копирайтом (уже сделано).
2. Релизы собирать **только в GitHub Actions**, а не у себя на компьютере: файл `.github/workflows/release.yml`
   в архиве. Он собирает `netfreedom.exe`, считает `SHA256SUMS.txt` и создаёт **аттестацию происхождения
   сборки** (build provenance), по которой любой может проверить, что exe собран именно из вашего репозитория
   и коммита. Workflow написан, но **я не мог запустить его здесь**: проверьте на тестовом теге (`v3.0.0-test`).
3. Одна официальная точка загрузки: GitHub Releases. Не раздавайте exe через сторонние зеркала и
   мессенджеры без хеша.
4. Не упаковывайте exe UPX и протекторами: это заметно увеличивает число ложных срабатываний.
5. Не изменяйте `winws.exe`, `WinDivert.dll` и `WinDivert64.sys`: драйвер WinDivert подписан его автором,
   и ваша подпись на нём не нужна и не поставится.
6. В программе есть команда `netfreedom verify`: сверяет все файлы пакета с `SHA256SUMS.txt` и печатает
   SHA-256 самой программы для сравнения с релизной страницей.

### 2.2. Цифровая подпись кода (главное для SmartScreen и Smart App Control)

| Вариант | Стоимость | Подходит ли вам |
|---|---|---|
| **SignPath Foundation** (бесплатно для открытого ПО) | 0 | Реальный кандидат. Условия: лицензия из списка OSI (GPL-3.0 подходит), публичный репозиторий, двухфакторная защита для всех участников, сборка и подписание через CI, строка-благодарность в README. Сертификат выписан на SignPath Foundation, то есть **издателем в окне Windows будет «SignPath Foundation»**, а не вы. Заявку могут отклонить: для инструмента обхода блокировок с драйвером перехвата пакетов гарантий нет |
| **Azure Artifact Signing** (бывший Trusted Signing) | низкая | По данным Microsoft: организации из США, Канады, ЕС, Великобритании; физические лица только из США и Канады. Если вы физическое лицо вне этих стран, **недоступно** |
| **OV-сертификат у коммерческого центра сертификации** | примерно 150-300 USD в год (оценка Microsoft) | Возможен. Закрытый ключ обязан храниться на аппаратном токене или в облачном HSM. Покупка для резидентов РФ может упираться в оплату и санкционные ограничения: уточняйте у конкретного центра |
| **EV-сертификат** | дороже | Мгновенной репутации не даёт (см. выше), смысла платить только ради этого нет |
| **Microsoft Store (MSIX)** | бесплатно | Store переподписывает пакет и предупреждений нет, но правила Store, драйвер перехвата пакетов, права администратора и тема обхода блокировок делают прохождение маловероятным. Рассчитывать не стоит |
| Самоподписанный сертификат | 0 | **Бесполезен** для чужих компьютеров: Windows ему не доверяет |

Рекомендуемый порядок: подать заявку в SignPath Foundation (https://signpath.org), параллельно выпускать
релизы с аттестацией из п. 2.1. В приложении к SignPath нужна страница политики подписи; шаблон в конце файла.

### 2.3. Репутация и ложные срабатывания

* Выпускайте **меньше версий** и не перезаливайте файл под тем же номером: у каждого хеша своя репутация.
* Загрузите релиз на https://www.virustotal.com, положите ссылку на отчёт в описание релиза.
* Ложное срабатывание Microsoft Defender: https://www.microsoft.com/en-us/wdsi/filesubmission
  (выберите «Software developer»). Для остальных антивирусов используйте форму ложных срабатываний
  производителя (Kaspersky, ESET, Dr.Web, Avast и т. д.): укажите ссылку на репозиторий и хеш.
* Публикация в **winget** (репозиторий `microsoft/winget-pkgs`): установка по проверяемому хешу из
  манифеста. Это даёт пользователям нормальный способ установки, но не обещает отсутствия предупреждений.

## 3. Что делать пользователю: проверить, а не «просто запустить»

1. Скачайте архив **только** со страницы Releases официального репозитория.
2. Сравните хеш с указанным в релизе (PowerShell):
   ```powershell
   Get-FileHash .\netfreedom.exe -Algorithm SHA256
   ```
3. Проверьте происхождение сборки (нужен GitHub CLI):
   ```powershell
   gh attestation verify .\netfreedom.exe --repo PsyGioX/NetFreedom
   ```
4. Запустите `netfreedom verify`: проверит остальные файлы пакета.
5. Когда появится подпись: ПКМ на файле → «Свойства» → «Цифровые подписи».
6. Можно собрать самому из исходников (`cargo build --release`), тогда доверять нужно только коду.

Если SmartScreen всё же показывает предупреждение, а хеш и аттестация совпали: «Подробнее» →
«Выполнить в любом случае», или ПКМ на файле → «Свойства» → «Разблокировать». Это снимает метку
загрузки (Mark of the Web) только с этого файла.

Чего **не** стоит делать: отключать SmartScreen или Defender целиком, добавлять в исключения диск или
профиль пользователя, запускать exe из чата или с чужого зеркала. Если без исключения не обойтись,
добавьте **только папку программы** и только после проверки хеша.
